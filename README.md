# MASTER PROMPT – HOTEL ISMINI
## Premium Mediterranean Luxury Hotel Website

---

# 1. PROJEKTÜBERSICHT

Entwickle eine vollständige, professionelle und hochwertige Hotel-Website für **Hotel Ismini**, ein luxuriöses Hotel in Griechenland.

Die Website soll aussehen, als wäre sie von einer professionellen internationalen Webdesign-Agentur entwickelt worden.

Das Ziel ist eine moderne Luxury-Hotel-Website mit:

- Hochwertigem und individuellem Design.
- Professioneller Benutzerführung.
- Flüssigen Animationen und Bildübergängen.
- Interaktiven Funktionen.
- Mehrsprachigkeit.
- Einem echten Buchungssystem mit Verfügbarkeitsprüfung.
- Hochwertiger KI-generierter oder lizenzierter Fotografie.
- Optimierter Ladegeschwindigkeit.
- Sauberem, verständlichem und modular aufgebautem Code.
- Vollständiger rechtlicher Grundstruktur für den späteren Betrieb.

Die Website soll nicht wie eine gewöhnliche Hotelvorlage aussehen.

**Wichtigste Priorität:** Ein außergewöhnliches Design mit einer professionellen technischen Umsetzung verbinden, ohne den Code unnötig kompliziert zu machen.

# 5. BUCHUNGSSYSTEM – WICHTIG

Implementiere ein funktionierendes Buchungssystem.

Eine reine visuelle Buchungsmaske reicht nicht aus.

Das System benötigt ein Backend und eine Datenbank oder eine Integration mit einem echten Hotelbuchungsanbieter.

### Buchungsformular

Der Gast soll folgende Angaben machen können:

- Check-in.
- Check-out.
- Anzahl der Erwachsenen.
- Anzahl der Kinder.
- Anzahl der Zimmer.
- Zimmerkategorie.
- Kontaktdaten.
- E-Mail-Adresse.
- Besondere Wünsche.

### Buchungsablauf

1. Gast öffnet die Buchungsmaske.
2. Gast wählt An- und Abreisedatum.
3. Gast wählt die Anzahl der Personen.
4. System prüft die tatsächliche Verfügbarkeit.
5. Verfügbare Zimmer werden angezeigt.
6. Gast wählt ein Zimmer.
7. Gast gibt seine Kontaktdaten ein.
8. System berechnet den Gesamtpreis anhand hinterlegter Preise.
9. Gast bestätigt die Buchung.
10. System erstellt eine Buchungsbestätigung.

### Technische Anforderungen

- Serverseitige Verfügbarkeitsprüfung.
- Korrekte Prüfung von An- und Abreisedaten.
- Keine Doppelbuchungen.
- Datenbank für Zimmer, Preise und Buchungen.
- Serverseitige Eingabevalidierung.
- Sichere Speicherung personenbezogener Daten.
- Eindeutige Buchungsnummer.
- Fehlerbehandlung.
- Schutz vor manipulierten Preisen.
- Zeitzone Europe/Athens.

Verfügbarkeiten und Preise dürfen niemals nur im Browser berechnet werden.

Bei konkurrierenden Buchungsanfragen müssen Datenbanktransaktionen oder gleichwertige Sperrmechanismen Doppelbuchungen verhindern.

### Zahlung

Falls eine Online-Zahlung implementiert wird, verwende einen professionellen Zahlungsanbieter mit gehosteter Zahlungsabwicklung.

Speichere niemals Kreditkartennummern oder Sicherheitscodes selbst.

Falls keine Zugangsdaten für einen echten Buchungsanbieter vorhanden sind, implementiere eine klar gekennzeichnete Entwicklungs- bzw. Demo-Umgebung.

Behaupte niemals, dass eine Buchung tatsächlich bestätigt wurde, wenn sie nicht erfolgreich im Backend gespeichert wurde.
